# ETRANOM V1995
هماهنگ‌سازی مهارت‌های رزمی نکرومنسر با سیستم کلکسیون ۱۴۰ همراه. فایل اصلی تغییرکرده: `game.js`، `systems/classes/necromancer.js` و `systems/classes/necromancer-common-companions-v1982.js`.

قانون قطعی: اثرهای رزمی فقط به حداکثر سه همراه احضارشده مربوط‌اند؛ کلکسیون نامحدود و همراهان ازپاافتاده حفظ می‌شوند و HP آن‌ها خودکار پر نمی‌شود.
