# ETRANOM V2013

این نسخه از V2012 ساخته شده است. تمرکز آن آغاز اتصال عملیاتی قوانین Owner به موتور پیشرفت است.

- `progression_rule.xp_multiplier` روی اعطای XP اثر می‌گذارد.
- `progression_rule.death_xp_loss_pct` و `death_gold_loss_pct` جریمه مرگ را کنترل می‌کنند.
- مقادیر پیش‌فرض بازی (۱ برابر XP، ۳٪ جریمه XP و ۱٪ جریمه طلا) بدون تنظیم Owner حفظ می‌شوند.
- Resolverهای ایمن برای قوانین اقتصاد، Guild، Party، PvP و class balance در دسترس هستند تا در مرحله بعد به RPCهای واقعی متصل شوند.

## نصب و تست
این ZIP را روی شاخه staging جایگزین کن و تست کن. SQL جدیدی ندارد. برای تغییرات عملیاتی سمت سرور و Supabase، تست staging و مهاجرت جداگانه لازم خواهد بود.
