# گزارش مرحله چهارم ETRANOM — نسخه کاری ۱

## تغییرات اعمال‌شده در این بسته

1. آواتار بازیکنان آنلاین روی نقشه جهان رسم می‌شود و فقط بازیکنانی نمایش داده می‌شوند که در همان شناسه منطقه حضور دارند.
2. رنگ دور آواتارها مطابق اولویت درخواستی است: دوست سبز، هم‌انجمنی طلایی، سایر بازیکنان خاکستری/سفید. اگر بازیکن هم دوست و هم‌انجمنی باشد، دوستی اولویت دارد.
3. نام و سطح بازیکن بالای آواتار نمایش داده می‌شود.
4. لمس/کلیک روی آواتار، کارت عمومی بازیکن را باز می‌کند و در صورت دوست نبودن، امکان ارسال درخواست دوستی از همان کارت وجود دارد.
5. تغییرات حضور نقشه از طریق callback به رویداد مرورگر منتشر می‌شوند؛ رسم آواتارها در حلقه نقشه از وضعیت Realtime استفاده می‌کند.
6. در تابع SQL پایان نشست گروه، بخش جست‌وجو و قفل‌کردن نشست فعال اصلاح شد. نسخه قبلی در این نقطه عبارت `WHERE` بدون دستور `SELECT` داشت و SQL معتبر نبود.

## آنچه هنوز تکمیل نشده است

این بسته را نباید «نبرد گروهی کامل» یا «مرحله چهارم نهایی» تلقی کرد. کد فعلی Party فقط ساخت/آمادگی/شروع و پایان یک نشست گروهی را مدیریت می‌کند. موتور نبرد زنده و همگام‌شده هنوز پیاده‌سازی نشده است:

- چرخه نوبت‌های مشترک، ثبت اکشن/مهارت بازیکنان و محاسبه معتبر HP/MP؛
- همگام‌سازی سلامت و وضعیت دشمن/باس برای همه اعضا؛
- تعیین حضور/غیبت اعضا در محل واقعی نبرد و ورود مجدد؛
- ذخیره و بازیابی snapshot نبرد پس از قطع اتصال؛
- توزیع پاداش معتبر سمت سرور و ثبت کشتن باس؛
- آزمایش چندحسابی واقعی روی Supabase.

این موارد عمداً به‌صورت محاسبه سمت مرورگر یا پاداش قابل‌دستکاری پیاده نشده‌اند. تابع `finish_party_session` در SQL فعلی صرفاً نشست را می‌بندد و پاداش نمی‌دهد؛ این رفتار حفظ شده است.

## بررسی‌هایی که انجام نشده‌اند

- اجرای SQL روی پروژه زنده Supabase؛
- ورود هم‌زمان دو یا چند حساب واقعی؛
- بررسی Realtime در شبکه واقعی و دستگاه‌های مختلف؛
- آزمون لمس آواتار روی موبایل واقعی؛
- تست نهایی Cloudflare Pages پس از push.

## دستورالعمل اعمال

1. فایل‌های این بسته را جایگزین نسخه فعلی مخزن کن.
2. در صورت نیاز به اصلاح تابع نشست گروه، فایل `database/party.sql` را در SQL Editor پروژه Supabase اجرا کن. اجرای مجدد فایل کامل ممکن است وابسته به ترتیب مهاجرت‌های قبلی باشد؛ پیش از اجرا از دیتابیس نسخه پشتیبان بگیر.
3. سپس تغییرات را به GitHub push کن تا Cloudflare Pages نسخه تازه را منتشر کند.
4. برای آزمون آواتارها، با دو حساب جداگانه وارد شو، هر دو را در یک منطقه قرار بده، و روی آواتار حساب دوم لمس کن.

**وضعیت:** تکمیل بخش تعامل آواتار نقشه و اصلاح SQL نشست گروه؛ موتور نبرد گروهی و آزمون زنده هنوز باز است.
