# مرحله ۲ آنلاین‌سازی ETRANOM: پیام خصوصی دوستان

## دامنه پیاده‌سازی
- تب «پیام‌ها» به مرکز اجتماع بازیکنان افزوده شد.
- فهرست دوستان تأییدشده برای انتخاب مخاطب استفاده می‌شود.
- پیام‌ها با Supabase در جدول `private_messages` ذخیره می‌شوند.
- دریافت زنده پیام‌ها با دو کانال Realtime (ارسالی و دریافتی) انجام می‌شود.
- هنگام خروج از مرکز اجتماع یا تغییر مخاطب، کانال‌های قبلی پاک‌سازی می‌شوند.
- متن پیام حداکثر ۲۰۰۰ نویسه است و در رابط با escape نمایش داده می‌شود.

## امنیت پایگاه داده
فایل `database/private_chat.sql` باید در SQL Editor پروژه Supabase اجرا شود. سیاست‌های RLS خواندن را به فرستنده/گیرنده محدود می‌کنند و ارسال را فقط برای کاربر واردشده و رابطه دوستی ثبت‌شده مجاز می‌کنند. Presence برای مجوزدهی استفاده نمی‌شود.

## خارج از دامنه این مرحله
چت عمومی و چت گروهی در این مرحله اضافه نشده‌اند؛ مرحله فعلی فقط پیام خصوصی بین دوستان تأییدشده است. چت گروهی/عمومی بدون تصمیم صریح بعدی به بازی افزوده نمی‌شود.

## وضعیت آزمون
آزمون نحوی و بررسی ساختار فایل‌ها به‌صورت محلی انجام می‌شود. اتصال واقعی Realtime، اجرای SQL روی Supabase و تبادل پیام بین دو حساب واقعی تا زمان اجرای migration و آزمایش روی سرویس زنده تأییدشده محسوب نمی‌شوند.
