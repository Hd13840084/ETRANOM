# پل کامپایلر اثر مهارت‌ها — V1957

## هدف

ساخت یک پل آزمایشی و قابل ممیزی میان تعریف‌های واقعی ۸ تخصص فعال و قرارداد Effect Plan موتور V1956. این نسخه مسیر زنده نبرد را تغییر نمی‌دهد.

## دامنه واقعی

- منبع داده: `IMPLEMENTED_SPECIALIZATION_DATA_V1939`؛ نه فایل‌های placeholder عمومی.
- تعداد تخصص‌های بررسی‌شده: ۸.
- تعداد مهارت‌های موجود در این ۸ تخصص: ۸۰ (۱۰ مهارت برای هر تخصص).
- مهارت‌هایی که برای مجموعه‌ای از primitiveهای V1956 نگاشت آزمایشی دارند: ۲۲.
- مهارت‌هایی که به adapter اختصاصی نیاز دارند: ۵۸.
- فهرست دقیق هر مهارت در `reports/V1957_SKILL_EFFECT_COVERAGE_AUDIT.json` است.

## رفتار ایمنی

- کامپایلر فقط از تعریف‌های سمت‌سرور واردشده از کاتالوگ تخصص‌ها استفاده می‌کند؛ مقدار effect از payload کلاینت نمی‌گیرد.
- مهارت فاقد نگاشت اختصاصی با خطای `skill_requires_specialized_effect_adapter` رد می‌شود؛ هیچ fallback عمومی حدسی وجود ندارد.
- مهارت رتبه بالاتر از ۱، یا دارای talent modifier / Domain / Ascension فعال، تا زمان نگاشت progression رد می‌شود.
- این کامپایلر shadow-only است و parity آن با resolverهای legacy اثبات نشده است.
- نگاشت primitive به معنی تأیید کامل رفتار، عدد، boss rule، charge، cleanse، geometry، summon/legion، انتخاب شاخه یا اثرهای جانبی نیست.

## اتصال

- export تشخیصی از `systems/combat/engines/index.js` اضافه شد.
- به `index.html`، مسیر Solo، Party، PvP، دیتابیس یا سرور authoritative وصل نشده است.
- هیچ SQL یا migration ایجاد یا اجرا نشده است.

## آزمون‌ها

۶ آزمون اختصاصی:
1. ممیزی ۸ تخصص و ۸۰ مهارت.
2. کامپایل مهارت‌های allow-list شده از داده سمت‌سرور.
3. رد مهارت‌های بدون adapter اختصاصی.
4. اجرای نمونه از مسیر V1956 و پرداخت منبع به‌صورت اتمیک.
5. رد رتبه و progression فاقد نگاشت.
6. رد شناسه‌های ناشناخته.

این آزمون‌ها صحت قرارداد و fail-closed بودن را بررسی می‌کنند؛ جایگزین تست differential با runtime واقعی نیستند.

## گام بعدی

V1958 باید adapterهای اختصاصی را بر اساس هر مهارت تکمیل کند؛ سپس برای هر ۸۰ مهارت، رتبه‌های ۱ تا ۷، استعدادها، Domain/Ascension، محدودیت باس و رفتار Solo/Party/PvP با resolver قدیمی مقایسه شوند. فقط پس از parity و تراکنش سرور می‌توان درباره cutover تصمیم گرفت.
