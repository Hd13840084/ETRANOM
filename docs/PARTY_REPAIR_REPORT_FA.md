# گزارش اصلاح و یکپارچه‌سازی Party

این بسته بر پایه فایل‌های ZIP شاخه main ساخته شده است. منطق اصلی بازی (`game.js`) و محتوای بازی عمداً تغییر داده نشده‌اند.

## تغییرات
- ایجاد `index.html` به‌عنوان ورودی استاندارد Cloudflare Pages، با حفظ فایل HTML اصلی.
- ایجاد `systems/party/party-config.js` برای پنج منطقه معتبر مرحله اول.
- بازیابی و اصلاح `systems/party/party.js` بر اساس RPCهای موجود در `database/party.sql`.
- هماهنگ‌سازی خواندن ساختار گروه و وضعیت آماده‌بودن اعضا در `party-manager.js` و `party-combat.js`.
- بارگذاری `party.css` در ورودی HTML.
- حفظ فایل‌های SQL و سایر سیستم‌ها بدون تغییر ساختاری.

## محدودیت آزمون
آزمون نحوی JavaScript و بررسی سازگاری نام RPCها به‌صورت محلی انجام شده است. این بسته به Supabase زنده متصل نشده و آزمون چندحسابی/Realtime واقعی انجام نشده است. فایل‌های SQL در این بسته تغییر نکرده‌اند و نباید دوباره اجرا شوند مگر اینکه بررسی جداگانه‌ای ضرورت آن را ثابت کند.

## انتشار
پس از جایگزینی محتویات شاخه `main` با محتویات این بسته، Cloudflare Pages باید از همان شاخه build شود.
