# ارتقای ظاهری اجتماع بازیکنان و حضور آنلاین

- فایل CSS مستقل و محدود به پنل اجتماع بازیکنان اضافه شد.
- دکمه اجتماع، پنجره، سربرگ، نشان اتصال، تب‌ها، کارت‌ها، دکمه‌ها و ورودی جست‌وجو بازطراحی شدند.
- وضعیت آنلاین/آفلاین دوستان با نشانگرهای دیداری متمایز نمایش داده می‌شود.
- چیدمان موبایل، فوکوس صفحه‌کلید و کاهش حرکت برای دسترس‌پذیری در نظر گرفته شد.
- منطق حساب، ذخیره، نقشه، مبارزه، تجهیزات، Party، SQL و داده‌های بازیکنان تغییر نکردند.

آزمون‌های نحوی، اعتبارسنجی محتوا، رگرسیون و آزمون شبیه‌سازی Presence اجرا شدند. این بسته هنوز روی مرورگر واقعی یا Supabase زنده آزمایش نشده است.
