# سیستم تجربه و ارتقای سطح ETRANOM

## قواعد اصلی
- سقف سطح فعلی: ۵۰.
- XP موردنیاز هر سطح، مقدار مستقل برای رفتن از سطح جاری به سطح بعد است؛ XP باقی‌مانده پس از ارتقا منتقل می‌شود.
- نیاز XP برای ارتقا: سطح ۱→۲: ۱۰۰؛ ۲→۳: ۲٬۳۰۰؛ ۳→۴: ۳٬۸۰۰؛ ۴→۵: ۵٬۷۰۰.
- از سطح ۵ به بعد XP موردنیاز به‌شدت افزایش می‌یابد؛ ارتقای سطح ۵ به ۶ دقیقاً ۲۵٬۰۰۰ XP نیاز دارد و هر سطح بعدی نیز دشوارتر می‌شود.
- هر ارتقا: ۲ امتیاز مهارت و ۵ امتیاز ویژگی آزاد.
- هر ارتقا: ۱۲ حداکثر سلامت، ۵ حداکثر مانا و ۴ حداکثر استقامت بیشتر؛ منابع در زمان ارتقا بازیابی می‌شوند.
- در سطح ۵۰ ارتقای بیشتری انجام نمی‌شود.
- هر بار مرگ: ۳٪ از XP ذخیره‌شده برای سطح فعلی و ۱٪ از طلای همراه بازیکن کسر می‌شود؛ سطح و امتیازهای کسب‌شده کاهش نمی‌یابند.
- XP مأموریت‌های فعلی به یک مسیر واحد اعطای XP متصل شده تا ارتقا در تمام این پاداش‌ها اعمال شود.
