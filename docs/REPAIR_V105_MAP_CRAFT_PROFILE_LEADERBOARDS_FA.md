# اصلاحات نسخه ۱۰۵
- جای فیزیکی جنگل سوخته و بیشه خارزار در نقشه آغازین جابه‌جا شد؛ نقاط ورود و چندضلعی‌ها نیز همراه آن‌ها جابه‌جا شدند.
- پنل ساخت آهنگر هنگام تعامل مستقیم با NPC برام معتبر است؛ رویداد کلیک ساخت از انتشار ناخواسته جلوگیری می‌کند و گزارش ساخت نمایش داده می‌شود.
- اسکرول پنجره تعامل هنگام بازسازی رابط در عنصر واقعی اسکرول حفظ می‌شود.
- آمار هیولا و باس فقط هنگام تأیید نهایی پیروزی ثبت می‌شود و شمارنده‌ها در ذخیره بازیکن باقی می‌مانند.
- ذخیره بازی، سطح و کلاس پروفایل اجتماعی را همگام می‌کند.
- رتبه بالاترین سطح از بیشینه سطح پروفایل و سطح ثبت‌شده در ذخیره استفاده می‌کند؛ رتبه کشتار از شمارنده‌های صریح ذخیره می‌خواند، نه متن ژورنال.
- پس از این تغییر، فایل `database/leaderboards_all10_phase2.sql` باید در Supabase SQL Editor دوباره اجرا شود تا تابع رتبه‌بندی جدید جایگزین شود.
