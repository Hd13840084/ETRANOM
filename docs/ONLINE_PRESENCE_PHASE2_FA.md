# تکمیل حضور آنلاین ETRANOM — مرحله ۲

## تغییرات
- چرخه شروع/توقف Presence مقاوم‌تر شد و از شروع هم‌زمان چندباره جلوگیری می‌کند.
- callbackهای کانال قدیمی پس از توقف یا جایگزینی نشست نادیده گرفته می‌شوند.
- وضعیت‌های خطا و قطع کانال گزارش می‌شوند؛ اتصال مجدد همچنان بر عهده رفتار Realtime SDK است.
- heartbeat هنگام اتصال فعال هر ۴۵ ثانیه و با تغییر visibility صفحه به‌روزرسانی می‌شود.
- در رخداد `pagehide` وضعیت موقت `DISCONNECTING` نمایش داده می‌شود؛ حذف واقعی حضور پس از بسته‌شدن اتصال توسط Realtime انجام می‌شود.
- شمارش حساب‌های یکتا از تعداد نشست‌ها جدا شده است؛ چند تب/دستگاه از یک حساب یک بازیکن آنلاین و چند نشست شمرده می‌شوند.
- فهرست دوستان وضعیت آنلاین/آفلاین را از Presence زنده می‌گیرد و هنگام تغییر حضور تازه‌سازی می‌شود.
- هیچ جدول، ستون یا داده ذخیره‌شده‌ای تغییر نکرده است.

## آزمون‌های محلی
- `node --check game.js` موفق.
- بررسی نحوی فایل‌های JavaScript زیر `systems/` موفق.
- `node tools/validate-content.mjs` موفق.
- `node tools/phase2-regression-check.mjs` موفق.
- آزمون شبیه‌سازی Presence شامل subscribe، چند نشست برای یک حساب، شمارش حساب یکتا، تازه‌ترین metadata و پاک‌سازی کانال موفق.

برای اجرای آزمون حضور آنلاین از پوشه پروژه:

```bash
node --experimental-default-type=module tools/tests/online-presence.test.mjs
```

آزمون با Node.js نسخه‌ای که گزینه `--experimental-default-type=module` را پشتیبانی می‌کند اجرا می‌شود.

## موارد تأییدنشده
- این محیط به پروژه زنده Supabase دسترسی اجرایی ندارد؛ آزمون با دو حساب واقعی، قطع/وصل اینترنت و رفتار شبکه موبایل هنوز انجام نشده است.
- Presence فقط وضعیت تقریبی برای رابط کاربری است و منبع مجوز یا داده پایدار نیست.
- `pagehide` تضمین نمی‌کند رویداد خروج فوراً به سرور برسد؛ در قطع ناگهانی، پاک‌شدن حضور تابع تشخیص قطع اتصال Supabase Realtime است.
