# اعلان‌های داخل بازی ETRANOM

این به‌روزرسانی برای مرکز اجتماع بازیکنان اعلان‌های زنده و شمارنده اضافه می‌کند:

- پیام خصوصی دریافتی: شمارنده قرمز روی دکمه اجتماع و تب پیام‌ها؛ تعداد پیام‌های خوانده‌نشده از ۱ تا ۹۹ و سپس 99+ نمایش داده می‌شود.
- پیام جدید چت جهانی: شمارنده خوانده‌نشده روی تب چت جهانی.
- درخواست دوستی دریافتی: شمارنده روی تب درخواست‌ها.
- دعوت گروه ماجراجویان: شمارنده روی تب گروه، با بازیابی دعوت‌های فعال از تابع get_party_invites.
- اعلان کوتاه بالای صفحه هنگام دریافت پیام/درخواست/دعوت، وقتی پنل اجتماع باز نیست.
- بازکردن بخش مربوطه، اعلان‌های خوانده‌نشده همان بخش را پاک می‌کند. زمان آخرین مشاهده در localStorage همان دستگاه ذخیره می‌شود.

این نسخه به SQL جدید نیاز ندارد؛ از جدول‌ها و RPCهای موجود مرحله ۲ و سیستم Party استفاده می‌کند. شمارنده‌ها در هر ورود دوباره از Supabase بازیابی می‌شوند. برای آزمایش اعلان‌های زنده، دو حساب واقعی لازم است.
