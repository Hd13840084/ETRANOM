# موتور مرکزی کلاس‌ها و تخصص‌ها — V1955

## هدف این مرحله

ساخت پایه مشترک برای ۱۰ کلاس و ۴۰ تخصص ETRANOM، با حفظ ۸ تخصص پیاده‌سازی‌شده (۴ جادوگر و ۴ جنگجو) و آماده‌بودن ۳۲ جایگاه آینده بدون قابل‌بازی‌کردن یا ساخت محتوای فرضی.

## آنچه در V1955 اضافه شد

- موتور مرکزی آماده‌سازی مهارت در `systems/combat/engines/central-specialization-engine-v1955.js`.
- استفاده از Registry موجود با ۱۰ کلاس، ۴۰ تخصص، ۸ تخصص فعال و ۳۲ تخصص رزروشده.
- ممیزی ساختار محتوای هر ۸ تخصص؛ ابعاد مورد انتظار: ۱۰ مهارت، ۴ شاخه استعداد، ۳۲ استعداد، ۴ مرحله قلمرو و ۱۰ تعالی.
- آماده‌سازی یکسان مهارت برای Solo، Party و PvP.
- بررسی شناسه canonical، قابل‌بازی‌بودن تخصص، سطح مهارت، هدف، cooldown، منبع و اعتبار استعدادها.
- محاسبه رتبه مهارت از ۱ تا ۷ و شش مرحله ارتقا با موتور مشترک.
- تفکیک درست هزینه منبع درصدی جادوگر از هزینه ثابت استقامت جنگجو در preflight.
- ساخت snapshot آمار و trace منابع modifierهای استعداد، ارتقای مهارت، قلمرو و تعالی.
- اتصال تشخیصی اختیاری در `index.html`؛ موتور فقط در `window.ETRANOM_CENTRAL_CLASS_ENGINE` و گزارش ممیزی آن در `window.ETRANOM_CENTRAL_CLASS_ENGINE_AUDIT` در دسترس قرار می‌گیرد.

## مرز ایمنی و مواردی که هنوز انجام نشده‌اند

V1955 عمداً یک موتور **prepare/preflight و shadow-safe** است، نه cutover اجرای نبرد. مسیرهای زنده فعلی Solo، Party و PvP همچنان authoritative باقی می‌مانند. این نسخه:

- هیچ فرمول آسیب یا چرخه نوبت فعلی را جایگزین نمی‌کند.
- هیچ SQL یا migration جدیدی ندارد.
- هیچ تغییری در دیتابیس Supabase، GitHub یا هاست اعمال نمی‌کند.
- اجرای واقعی effectها، transaction اتمیک سرور، ذخیره‌سازی پیشرفت و تطبیق رفتاری کامل را ادعانمی‌کند.

## آزمون‌ها

فایل `tests/central-class-engine-v1955.test.mjs` شامل ۶ آزمون است:

1. حفظ دقیق ۱۰ کلاس / ۴۰ تخصص / ۸ فعال / ۳۲ رزروشده.
2. اعتبارسنجی ابعاد محتوایی هر ۸ تخصص.
3. آماده‌سازی ۸۰ مهارت در سه حالت نبرد؛ ۲۴۰ بررسی بدون mutation ورودی.
4. تشخیص هزینه درصدی مانا و هزینه ثابت استقامت.
5. جلوگیری از اجرای preflight برای جایگاه‌های رزروشده.
6. رد mode، هدف، cooldown و منبع نامعتبر.

## مرحله بعد

مرحله بعدی، ساخت Effect Resolver و Combat Lifecycle مرکزی با ترتیب قطعی رویدادها، اجرای اتمیک هزینه/کول‌داون، multi-hit، status tick، reaction و summon است. اتصال واقعی فقط پس از تست parity جداگانه برای هر ۸ تخصص و هر سه حالت نبرد انجام می‌شود.

## نتیجه آزمون کل مخزن

- آزمون‌های هدفمند موتور مرکزی و وابستگی‌های مستقیم: ۴۶ موفق، صفر ناموفق.
- آزمون‌های کل مخزن: ۶۴۷ مورد؛ ۶۳۸ موفق و ۹ ناموفق. هر ۹ مورد در assertionهای قدیمی و خارج از فایل‌های موتور مرکزی است (سه مورد تست v106، و یک مورد از هرکدام از تست‌های save safety، equipment، UI cache-buster، entry point، interaction cache-buster و feedback v1852). این موارد پنهان یا به‌عنوان موفق گزارش نشده‌اند.
- بررسی syntax برای ۵۸ فایل JavaScript: بدون خطا.
