# تکمیل نهایی دژ پولادین — V1874

## اصلاحات اجرایی
- هنگام فعال‌سازی تختگاه تایتان، actor بازگشتی Runtime اکنون به وضعیت شخصیت منتقل می‌شود؛ بنابراین افزایش دفاع/مقاومت/حمله قلمرو واقعاً در وضعیت مبارزه اعمال می‌شود.
- پس از اجرای تعالی، وضعیت UI همان نبرد به‌روزرسانی می‌شود تا پنل انتخاب تعالی دوباره نمایش داده نشود؛ تعالی همچنان از همان جایگاه مهارت پایه اجرا می‌شود.
- پاک‌سازی اثرات قلمرو دیگر کل `combatEffects` را به snapshot قدیمی برنمی‌گرداند. فقط مقادیر افزوده‌شده توسط قلمرو حذف می‌شوند و اثرات دیگری که در طول قلمرو دریافت شده‌اند باقی می‌مانند.
- ظاهر اختصاصی قلمرو در صفحه نبرد اضافه شد: نشانگر نام قلمرو، مرحله و نوبت‌های باقی‌مانده، قاب و هاله متناسب با چهار مرحله، و انیمیشن ملایم با رعایت `prefers-reduced-motion`.
- نسخه cache ماژول Runtime در ورودی و adapterها به V1874 تغییر کرد.

## تست‌ها
- ۹ آزمون اختصاصی Runtime دژ پولادین موفق.
- بررسی نحوی `game.js` و `iron-bastion-runtime.js` موفق.
- آزمون‌های bridge و adapter در مسیرهای solo/party/PvP در تست هدفمند Runtime اجرا شدند.
- تست مرورگر واقعی موبایل، اتصال زنده Supabase و PvP چندکاربره آنلاین در این محیط انجام نشده‌اند.

## محدوده تغییر
فقط Runtime دژ پولادین، اتصال UI آن، استایل‌های قلمرو، نسخه cache و آزمون‌های اختصاصی مرتبط تغییر کرده‌اند. فایل‌های احراز هویت، بازار، نقشه، محتوا و SQL دست‌کاری نشده‌اند.

## وضعیت تخصص
ساختار طراحی و اتصال محلی دژ پولادین کامل است: ۱۰ مهارت، ۶ رتبه، ۳۲ استعداد با امتیاز مهارت، قلمرو چهارمرحله‌ای و ۱۰ تعالی نام‌دار که در هر بار قلمرو فقط یکی اجرا می‌شود. قبل از اعلام آماده‌بودن برای انتشار، تست دستی روی دستگاه و اعتبارسنجی سرور آنلاین همچنان لازم است.
