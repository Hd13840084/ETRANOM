# نقشه تکمیل ETRANOM Owner Control

## وضعیت تا V2005
- V2003: هسته نقش، Owner ثابت، audit، ban record، مخزن JSON مدیریتی و پنل پایه.
- V2004: بارگذاری پنل بعد از شروع موفق بازی، هماهنگی فهرست بازیکنان با schema واقعی و اصلاح UX عملیات ban.
- V2005: پرونده فقط‌خواندنی بازیکن با پروفایل، save_data و وضعیت ban؛ ثبت مشاهده در audit. Import قدیمی پیش از ورود حذف شد.

## کارهای باقی‌مانده
1. اتصال ban به ورود، نشست‌ها و تمام RPCهای بازی؛ فعلاً فقط رکورد ban ذخیره می‌شود.
2. ابزارهای امن و schema-aware برای تغییر XP، سطح، کلاس، تخصص، آمار، موجودی، تجهیزات و ارز.
3. اتصال محتوای منتشرشده به `systems/content/content-loader.js` و کاتالوگ‌های واقعی؛ مخزن JSON مدیریتی هنوز جداست.
4. فرم‌های تخصصی، اعتبارسنجی، preview، انتشار اتمیک و rollback.
5. مدیریت دیالوگ NPC، AI هیولا، فرمول مبارزه، مأموریت، Guild، Party، چت، بازار، PvP و رویدادها.
6. مدیریت فایل‌های تصویری، نقش مدیران و گردش تأیید Owner.

## اصل ایمنی
تا زمان پیاده‌سازی guard سمت سرور، بن را امنیت کامل ندانید. هیچ ویرایش مستقیمی روی `game_saves` از مرورگر اضافه نشود؛ تغییرات باید از RPCهای محدود، اعتبارسنجی‌شده و auditشده عبور کنند.
