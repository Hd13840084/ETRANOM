# رفع خطای هدیه و قید player_asset_transfer_shape — v131

- علت خطا: فرم هدیه مقدار انتخاب‌شده در فهرست آیتم را حتی هنگام انتخاب «سکه» نیز به RPC می‌فرستاد. قید دیتابیس برای انتقال سکه الزام می‌کند `item_id` تهی باشد.
- اصلاح سمت بازی: برای نوع دارایی `gold`، شناسه آیتم پیش از فراخوانی RPC به `null` تبدیل می‌شود.
- اصلاح دفاعی سمت دیتابیس: تابع RPC در زمان ثبت تاریخچه، برای سکه همیشه `item_id = NULL` ذخیره می‌کند؛ حتی اگر کلاینت قدیمی مقدار آیتم فرستاده باشد.
- انتقال آیتم همچنان شناسه واقعی آیتم را ثبت می‌کند.

## نصب
1. کل پوشه `ETRANOM-main` را روی مخزن اصلی جایگزین و deploy کنید.
2. فایل `database/player_gift_transfer_shape_fix_v131.sql` را در Supabase SQL Editor اجرا کنید.

این مهاجرت فقط تابع انتقال هدیه را جایگزین می‌کند و جدول یا سوابق قبلی را حذف نمی‌کند.
