# اتصال اجرایی دژ پولادین — V1872

## تغییرات این مرحله
- اتصال انتخاب تعالی در هر دو مسیر رابط کاربری (دفتر تخصص و صفحه نبرد) به اعتبارسنجی runtime؛ انتخاب مستقیم و بدون اعتبارسنجی از UI حذف شد.
- هنگام فعال بودن قلمرو و انتخاب تعالی، دکمه مهارت پایه متناظر در نوار مهارت نبرد با نام تعالی جایگزین می‌شود و همان دکمه، شناسه تعالی را اجرا می‌کند؛ بنابراین نام قدیمی و نسخه تعالی‌یافته به‌صورت دو مهارت موازی نمایش داده نمی‌شوند.
- پس از اجرای تعالی، دکمه مربوط تا پایان قلمرو غیرفعال می‌شود؛ انتخاب یا اجرای تعالی دوم همچنان در runtime رد می‌شود.
- نسخه cache runtime در index و adapterها به 1872 افزایش یافت.

## ساختار مشترک حفظ‌شده
- ۴ تخصص برای هر کلاس (ساختار کاتالوگ کلاس‌ها دست‌نخورده است).
- ۱۰ مهارت دژ پولادین با بازشدن سطح‌های ۱ تا ۱۰ و ۶ رتبه کلی برای هر مهارت.
- هر Level Up: دو امتیاز مهارت و پنج امتیاز ویژگی.
- ۳۲ استعداد در چهار شاخه؛ خرید استعداد فقط با امتیاز مهارت.
- یک قلمرو چهارمرحله‌ای و حداکثر یک تعالی در هر فعال‌سازی.

## سازگاری و ایمنی
- شناسه‌های `warrior_2` و `warrior_iron_bastion` حفظ شده‌اند.
- مسیرهای solo/party/PvP همچنان از adapter و runtime مشترک استفاده می‌کنند.
- منطق آنلاین، احراز هویت، بازار، نقشه، داده‌های منطقه و ذخیره‌های نامرتبط تغییر نکرده‌اند.

## آزمون‌ها
- آزمون‌های runtime دژ پولادین، پرتره، bridge، adapterها و shared combat اجرا می‌شوند.
- آزمون جدید بررسی می‌کند که نام تعالی جای نام مهارت پایه را در رابط نبرد می‌گیرد و هر دو مسیر انتخاب تعالی از اعتبارسنجی runtime عبور می‌کنند.
- این آزمون‌ها شبیه‌سازی/آزمون کد هستند؛ تست دستی مرورگر، سرور Supabase و بازی چندکاربره واقعی محسوب نمی‌شوند.
