# تکمیل مرحله ۲: چت عمومی و جهانی ETRANOM

## قابلیت افزوده‌شده
- تب مستقل «چت جهانی» در مرکز اجتماع بازیکنان.
- یک کانال مشترک برای همه حساب‌های واردشده؛ پیام‌ها وابسته به دوستی یا عضویت در Party نیستند.
- نمایش ۱۰۰ پیام آخر و دریافت زنده پیام‌های جدید از Supabase Realtime.
- نمایش نام بازیکن از `player_profiles` در سمت پایگاه داده؛ نام ارسالی کاربر پذیرفته نمی‌شود.
- محدودیت ۱۰۰۰ نویسه برای پیام و فاصله حداقل ۲ ثانیه بین پیام‌های هر بازیکن در پایگاه داده.
- پاک‌سازی کانال Realtime هنگام تغییر تب یا بستن مرکز اجتماع.
- پیام‌های خصوصی قبلی دست‌نخورده باقی مانده‌اند و چت جهانی جایگزین آن‌ها نیست.

## نصب پایگاه داده
فایل `database/global_chat.sql` را در Supabase SQL Editor اجرا کنید. اجرای آن نیازمند وجود جدول `player_profiles` با ستون‌های `user_id`، `display_name` و `username` است.

## امنیت و محدودیت‌ها
- فقط کاربران احراز هویت‌شده می‌توانند پیام‌ها را بخوانند یا ارسال کنند.
- RLS درج پیام را به شناسه حساب واردشده محدود می‌کند.
- trigger سمت سرور نام نمایشی را از پروفایل می‌گیرد و محدودیت ضداسپم را اعمال می‌کند.
- این نسخه ابزار گزارش، مسدودسازی کاربر، مدیر چت یا فیلتر واژگان ندارد؛ برای انتشار عمومی گسترده باید این ابزارهای نظارت و رسیدگی اضافه شوند.

## وضعیت آزمون
آزمون نحوی فایل جاوااسکریپت، بررسی ساختار HTML، و بررسی محتوای SQL در محیط محلی انجام می‌شود. اجرای migration و آزمون زنده با دو یا چند حساب واقعی روی Supabase هنوز باید انجام شود.
