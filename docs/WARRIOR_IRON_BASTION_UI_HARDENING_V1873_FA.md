# سخت‌سازی رابط تعالی دژ پولادین — V1873

## اصلاح انجام‌شده
- پس از انتخاب تعالی، نام تعالی در همان دکمه مهارت پایه نمایش داده می‌شود.
- پنل انتخاب تعالی دیگر دکمه اجرای تکراری تولید نمی‌کند؛ فقط نام تعالی انتخاب‌شده و راهنمای اجرای آن را نشان می‌دهد.
- اجرای تعالی از یک مسیر واحد انجام می‌شود و از نمایش دو کنترل موازی برای یک مهارت جلوگیری می‌شود.
- انتخاب همچنان از اعتبارسنجی runtime عبور می‌کند و محدودیت یک تعالی در هر قلمرو حفظ شده است.

## اعتبارسنجی
- `node --check game.js` موفق.
- آزمون‌های هدفمند Iron Bastion، bridge و UI: ۲۰ از ۲۰ موفق.
- نسخه cache ماژول runtime در ورودی‌ها و adapterها به ۱۸۷۳ هماهنگ شد.

## محدوده
این اصلاح فقط رابط انتخاب/اجرای تعالی و نسخه cache مرتبط را تغییر می‌دهد. منطق آنلاین، Supabase، SQL، محتوای مناطق و سایر تخصص‌ها تغییر نکرده‌اند.
