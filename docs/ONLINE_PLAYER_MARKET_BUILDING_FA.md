# افزودن ساختمان مستقل بازار آنلاین سپیده

- ساختمان مستقل «بازار آنلاین سپیده» به نقشه پیوسته شهر خاکستر اضافه شد.
- بازار NPC «بازار سپیده» بدون تغییر باقی مانده است.
- با نزدیک‌شدن به ساختمان جدید و زدن دکمه «تعامل»، پنجره تعامل ساختمان باز می‌شود.
- دکمه «ورود به بازار آنلاین بازیکنان» رابط موجود `ETRANOMMarketplaceUI` را باز می‌کند.
- نقطه ساختمان در اطلس شماتیک شهر خاکستر نیز ثبت شده است.
- هیچ جدول، RPC، policy یا مهاجرت SQL جدیدی اضافه نشده است؛ از RPCهای مرحله پنجم موجود استفاده می‌شود.

## انتشار
فایل‌های این ZIP را جایگزین نسخه مخزن کن و به شاخه `main` ارسال کن. سپس Cloudflare Pages را بررسی کن. این تغییر فقط اتصال مکانی و رابط نقشه را اصلاح می‌کند؛ برای عملکرد خریدوفروش، مهاجرت‌های قبلی بازار باید قبلاً با موفقیت اجرا شده باشند.
