# ETRANOM V1984

نسخه ادامه V1983 با آزادسازی دروازه دنیای مردگان، پنج مهر احضار و اتصال اثر مهارت‌های موجودات به موتور نبرد.

- مهارت دروازه با آیتم ویژه آزاد می‌شود و سطح/ارتقای مهارتی ندارد.
- کلکسیون موجودات نامحدود است؛ سه موجود هم‌زمان قابل احضارند.
- نمونه‌های تکراری مستقل هستند.
- HP موجودات پس از نبرد خودکار پر نمی‌شود.
- اثرهای چندهدفه، درمانی، دفاعی، کنترلی و تضعیفی در مسیر نبرد اجرا می‌شوند.
- در صورت نبود دفتر گونه برای رده‌ای که مهر انتخاب کرده، مهر مصرف نمی‌شود.
