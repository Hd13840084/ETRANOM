# ETRANOM V1961 — پاک‌سازی محتوای منطقه امن

منطقه امن به پوسته یکپارچه و قابل توسعه تبدیل شده است: نقشه، ساختمان‌ها، مکان‌های دیدنی، NPCها و گفتگوی پایه حفظ شده‌اند؛ اما فروشگاه، خریدوفروش محلی، مواد/کالاهای محلی، برداشت منابع، مأموریت‌ها، درخواست‌ها، هدایا، خدمات درمان/تعمیر/استراحت و پاداش‌های محلی از اجرای فعال حذف شده‌اند.

آیتم‌های اختصاصی حلقه قدیمی منطقه امن از موجودی ذخیره‌های قدیمی پاک می‌شوند؛ مواد مناطق خطر، تجهیزات، طلا، XP، دستورهای ساخت مناطق خطر و سیستم‌های آنلاین سراسری حفظ می‌شوند.

جزئیات مهاجرت در `docs/SAFE_ZONE_CONTENT_RESET_V1961_FA.md` است.

بازار آنلاین سراسری از منطقه خطر قابل دسترسی است و در منطقه امن مسدود می‌شود. ساخت و کیمیاگری تا طراحی کارگاه‌های یکپارچه از منوها برداشته شده‌اند؛ داده‌های دستورهای مناطق خطر و اسکرول‌های مبارزه برای استفاده بعدی حفظ شده‌اند.

موجودیت‌های نگه‌داشته‌شده: ۹ ساختمان، ۱۰ NPC و ۸ مکان دیدنی. چهار نقطه مخفی مرتبط با مأموریت‌های قبلی حذف شده‌اند. بازار آنلاین سراسری فقط از محدوده خطر باز می‌شود؛ ساخت و کیمیاگری تا طراحی کارگاه‌های یکپارچه از منوها برداشته شده‌اند.
