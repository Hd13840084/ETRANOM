# ETRANOM V1999

تنظیم دراپ مهر احضار نوع اول برای منطقه اول.

- عادی: ۱۵٪
- مینی‌باس: ۲۵٪
- باس نهایی: ۳۵٪

هیولاها، مینی‌باس‌ها، باس، مواد، دستورهای ساخت و آیتم‌های خروجی دستورها عمداً تغییر نکرده‌اند. دانجن و برج از نرخ منطقه‌ای مستثنا هستند. سایر مناطق نرخ‌های قبلی خود را حفظ می‌کنند.
