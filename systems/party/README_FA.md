# ETRANOM Party System

سیستم گروهی چهار نفره ETRANOM.

## امکانات

- ساخت گروه
- حداکثر چهار عضو
- دعوت دوستان
- پذیرش و رد دعوت
- تعیین رهبر
- انتقال خودکار رهبری هنگام خروج رهبر
- آماده‌باش اعضا
- انتخاب منطقه خطر
- شروع گروهی
- ثبت نتیجه ماجراجویی

## نیازمندی‌ها

- JavaScript ES Modules
- Supabase JavaScript Client
- Supabase PostgreSQL

## نصب

1. پوشه systems/party را ایجاد کنید.
2. فایل‌های JavaScript را در آن قرار دهید.
3. party.css را در رابط اصلی بارگذاری کنید.
4. فایل party.sql را پس از بازبینی ساختار دیتابیس اجرا کنید.
5. سپس ماژول را به بازی اصلی متصل کنید.

## امنیت

عملیات حساس باید با RPC سمت سرور انجام شوند.

کلید service_role نباید در کد مرورگر قرار گیرد.
