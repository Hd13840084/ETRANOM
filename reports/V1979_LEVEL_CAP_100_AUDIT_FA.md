# ممیزی V1979 — سقف سطح ۱۰۰

## دامنه تغییر
- سقف شخصیت در مسیر XP بازی از ۵۰ به ۱۰۰ افزایش یافت.
- جدول XP بازی ۹۹ آستانه دارد (برای ارتقا از سطح ۱ تا ۹۹). آستانه‌های موجود ۱ تا ۵۰ عیناً حفظ شدند؛ آستانه‌های ۵۱ تا ۱۰۰ با رشد پیوسته ۱۲٪ از مقدار قبلی ساخته شدند.
- ساختار XP محلی بازی همچنان XP باقی‌مانده سطح جاری است؛ API progression مستقل همچنان XP کل عمر را نگه می‌دارد. این دو قرارداد با هم مخلوط نشده‌اند.
- XP مأموریت، حلقه ارتقای سطح، سقف سطح، نمایش وضعیت XP و هزینه استراحت با سقف ۱۰۰ هماهنگ شدند.
- پاداش هر ارتقا ثابت ماند: ۲ امتیاز مهارت، ۵ امتیاز ویژگی، +۱۲ حداکثر HP، +۵ حداکثر MP، +۴ حداکثر استقامت و بازیابی منابع.
- progression API جدید در `systems/progression/character-progression-v1979.js` ایجاد شد؛ API و فایل V1977 برای سازگاری آزمون‌ها و نسخه تاریخی دست‌نخورده باقی ماندند.
- `engine-readiness-v1978.js` اکنون API progression نسخه V1979 را ممیزی می‌کند.
- levelCap داده‌های تخصص نکرومنسر و وارلاک و کاتالوگ تخصص‌های Wizard به ۱۰۰ تغییر کرد.
- شش فایل SQL منبعی که سطح شخصیت را در محاسبه آمار یا هزینه/پاداش به ۵۰ محدود می‌کردند، برای سطح شخصیت به ۱۰۰ اصلاح شدند.

## مرزهای عمداً حفظ‌شده
- سطح ۵۰ همچنان milestone دامنه/تعالی برای تخصص‌هایی است که قبلاً آن را تعریف کرده‌اند؛ این شرط به‌صورت خودکار به ۱۰۰ منتقل نشد.
- سطح هیولاها و سقف سطح آیتم‌ها همچنان ۵۰ است؛ این‌ها سقف شخصیت نیستند و افزایششان بدون طراحی مناطق و تجهیزات سطح ۵۱ تا ۱۰۰ تعادل بازی را به‌هم می‌زند.
- پاداش‌ها و آمار هیولا بر اساس طراحی محتوای فعلی تغییر داده نشدند.

## آزمون‌ها
- آزمون‌های هدفمند V1979 و progression قدیمی: ۱۳/۱۳ موفق.
- آزمون‌های readiness V1978: ۶/۶ موفق.
- کل مجموعه: ۱۰۲۶ موفق از ۱۰۷۴؛ ۴۸ شکست.
- نام ۴۸ شکست دقیقاً با baseline نسخه V1977 یکسان است؛ شکست تازه‌ای اضافه نشده است.
- بررسی syntax برای `game.js`، ماژول progression جدید و readiness بدون خطا؛ JSONهای تغییرکرده parse شدند.

## وضعیت انتشار آنلاین
هیچ SQL اجرا نشده و هیچ RPC زنده Supabase، GitHub یا Hosting تغییر نکرده است. فایل‌های SQL موجود در ZIP منابع اصلاح‌شده‌اند؛ توابعی که قبلاً روی Supabase مستقر شده‌اند تا بازبینی و بازاستقرار نسخه متناظر، ممکن است همچنان رفتار سقف ۵۰ داشته باشند. بنابراین این ZIP آماده انتشار فایل‌هاست، اما فعال‌شدن قطعی سقف ۱۰۰ در محیط آنلاین هنوز تأیید نشده است.
