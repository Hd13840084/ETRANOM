# ETRANOM V1960 — Safe Zone Unification Foundation

این نسخه پایه یکپارچه‌سازی منطقه امن را اضافه می‌کند. گزارش دقیق ممیزی و نقشه مراحل در `docs/SAFE_ZONE_UNIFICATION_AUDIT_V1960_FA.md` قرار دارد.

- Registry واحد NPC / Building / Landmark
- قرارداد مشترک شش‌بخشی برای پنجره تعامل
- متصدی استاندارد برای ساختمان‌ها
- گفت‌وگوی مشترک ساختمان از طریق متصدی
- دسترسی یکسان به مأموریت‌ها و کیف/تجهیزات
- فروش عمومی سازگار برای مکان‌های غیر landmark
- helperهای پایه برای item normalization و commerce quote

هیچ SQL یا deploy انجام نشده است. کدهای قدیمی اقتصاد و مأموریت در این مرحله حفظ شده‌اند تا مهاجرت مرحله‌ای و بدون از دست رفتن داده انجام شود.
