# ETRANOM V2008 — Owner Control: هم‌زمان‌سازی ۹ محور مدیریت

این نسخه، ناوبری پنل را به ۹ محور مدیریتی تبدیل می‌کند و چرخه نسخه‌بندی محتوای مدیریتی را تکمیل‌تر می‌کند.

## ۹ محور در پنل
1. بازیکنان و حساب‌ها
2. آمار و شخصیت
3. آیتم‌ها و تجهیزات
4. جهان، مناطق و هیولاها
5. NPC و مأموریت‌ها
6. کلاس‌ها، تخصص‌ها و مهارت‌ها
7. نبرد، AI و تنظیمات
8. اقتصاد، بازار و انجمن‌ها
9. عملیات، انتشار و تاریخچه

هر محور به ماژول‌های موجود پنل هدایت می‌شود: داده‌های زنده فقط در allowlist تعریف‌شده V4 قابل ویرایش‌اند؛ انواع محتوای دیگر در مخزن JSON مدیریتی به‌صورت draft ذخیره می‌شوند. V5 فهرست نسخه‌ها، بازگردانی نسخه به draft جدید و حذف draft را با audit اضافه می‌کند.

## SQL
فایل `database/admin/etranom_owner_control_v5_content_lifecycle.sql` را فقط پس از اجرای موفق V1 تا V4 اجرا کنید. ابتدا بکاپ و ترجیحاً محیط staging. V5 به جداول و توابع نسخه‌های قبلی وابسته است.

## محدودیت‌های مهم
- این نسخه به‌تنهایی به معنی اتصال همه فیلدهای ذخیره بازی یا همه کاتالوگ‌ها به موتور runtime نیست.
- انتشار مخزن `etranom_admin_content` هنوز adapter انتشار به `content-loader.js` یا کاتالوگ‌های واقعی را ندارد؛ وضعیت published در مخزن مدیریت است، نه تضمین تغییر محتوای بازی زنده.
- AI، فرمول مبارزه، دیالوگ/شرط مأموریت، تصاویر، و عملیات مالی/تاریخی حساس هنوز فرم تخصصی و اتصال runtime مستقل می‌خواهند.
- جدول‌های پیام، تراکنش، تاریخچه، ذخیره بازیکن و عضویت‌ها از عملیات حذف عمومی مستثنا هستند.
- هیچ SQL یا تغییر دیتابیس زنده‌ای از اینجا اجرا نشده است.

## تست
تست‌های ایستا و syntax با Node اجرا می‌شوند؛ این تست‌ها جای تست واقعی Supabase و بازی را نمی‌گیرند.
