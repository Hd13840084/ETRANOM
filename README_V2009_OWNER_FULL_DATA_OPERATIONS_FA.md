# ETRANOM V2009 — ویرایش داده‌های بازی

این نسخه عملیات جدیدی برای ویرایش کامل JSON ذخیره بازیکن و ایجاد/حذف ردیف در allowlist محدود کاتالوگ‌ها اضافه می‌کند.

## نصب
فایل `database/admin/etranom_owner_control_v6_full_data_operations.sql` را فقط بعد از V1، V2، V3، V4 و V5 و پس از backup، ابتدا در staging اجرا کنید.

## بخش‌های فعال
- پرونده بازیکن: ویرایش JSON کامل `game_saves.save_data` از RPC امن و ثبت before/after در audit.
- ویرایشگر داده زنده: ویرایش ردیف‌های مجاز، ایجاد ردیف و حذف ردیف برای جدول‌های allowlist شده جهان/مهارت.
- مدیریت محتوا: ذخیره draft، انتشار در مخزن مدیریتی، نسخه‌بندی و rollback-to-draft.

## مواردی که هنوز «کامل و متصل به runtime» نیستند
- `etranom_admin_content` یک مخزن مدیریتی است؛ publish در آن خودبه‌خود فایل‌های static یا موتور بازی را تغییر نمی‌دهد.
- NPC، Quest، آیتم‌ها، فروشگاه‌ها، هوش مصنوعی و تنظیمات نبرد نیازمند اتصال runtime loader و فرم/اعتبارسنجی دامنه‌ای هستند.
- اجرای SQL در Supabase، احراز Owner واقعی و تست زنده از این محیط ممکن نیست.

## تست‌ها
۸ تست متمرکز پنل Owner موفق شدند. در کل مخزن ۱۱۷۱ تست اجرا شد: ۱۰۵۹ موفق و ۱۱۲ ناموفق؛ شکست‌ها عمدتاً در قراردادهای قدیمی کلاس/مهارت/بالانس دیده شدند. بنابراین این نسخه برای انتشار production تأیید نشده است.
