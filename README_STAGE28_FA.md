# ETRANOM V2170 — بسته کامل مرحله ۲۸

این ZIP شامل کل پروژه، همه دارایی‌ها، کدها، سیستم‌ها، داده‌ها و آزمون‌های نسخه پایه به‌علاوه اصلاحات مقیاس جهان V2170 است.

## نصب
پوشه `etranom_v2166` را به‌عنوان ریشه پروژه نگه دارید و کل محتویات ZIP را روی نسخه فعلی پروژه جایگزین کنید. فایل‌های این بسته کامل‌اند؛ از نصب گزینشی چند فایل استفاده نکنید.

## اعتبارسنجی محلی

```bash
node --check game.js
node --test tests/v2170/world-scale-calibration-v2170.test.mjs
```
