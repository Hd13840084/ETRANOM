# ETRANOM V2006 — گسترش پنل Owner

این نسخه پنل را از چهار بخش اولیه به یک کنسول عملیاتی گسترده‌تر ارتقا می‌دهد.

## بخش‌های پنل
- داشبورد مدیریتی موجود
- شمارنده‌های زنده جدول‌های واقعی Supabase
- فهرست بازیکنان و پرونده بازیکن (مشاهده‌ای)
- مدیریت پیش‌نویس‌های JSON و انتشار در مخزن مدیریتی
- مرور فقط‌خواندنی داده‌های جهان، هیولاها، مواد و دستورها
- مرور مهارت‌ها، گروه‌ها، نبرد گروهی و PvP
- مرور بازار، تراکنش‌ها، انجمن‌ها و اعضا
- مرور پیام‌های عمومی/خصوصی
- مرور ذخیره‌ها، تاریخچه و تعارض‌های ذخیره
- مدیریت نقش‌ها و مجوزها (فقط Owner اصلی)
- گزارش اقدامات مدیران

## SQL جدید
فایل `database/admin/etranom_owner_control_v3_live_operations.sql` را بعد از V1 و V2 اجرا کنید. این فایل همچنین RPC مدیریت نقش‌ها را فقط برای Owner اصلی اضافه می‌کند. این فایل فقط دو RPC خواندنی اضافه می‌کند و داده‌های بازی را تغییر نمی‌دهد.

## محدودیت‌های صریح
- پنل هنوز ابزار ویرایش مستقیم همه جدول‌های اصلی بازی را ندارد.
- پیش‌نویس/انتشار در `etranom_admin_content` به‌تنهایی محتوای hard-coded یا loader فعلی بازی را تغییر نمی‌دهد.
- بن فعلی صرفاً در جدول مدیریتی ثبت می‌شود و هنوز ورود، نشست‌ها و RPCهای گیم‌پلی را مسدود نمی‌کند.
- مدیریت نقش‌ها، rollback محتوا، ویرایش امن اقتصاد/بازیکن و اتصال enforcement سروری در مراحل بعدی لازم‌اند.
- هیچ تستی روی پروژه Supabase یا سایت زنده اجرا نشده است.
