# ETRANOM V1966 — انتقال Solo و Party به رابط نبرد مرکزی

در این نسخه، صفحه نبرد تکی و گروهی نیز به `renderUnifiedBattleScreenV1963` منتقل شدند. PvP از V1965 روی همان رندرکننده قرار داشت؛ بنابراین هر سه حالت Solo، Party و PvP اکنون از یک ساختار نمایشی و اجزای مشترک استفاده می‌کنند.

- Solo: کارت بازیکن، قاب نبرد، گزارش، نوار عملیات و ساختار دشمنان از رابط مرکزی تولید می‌شود. کارت‌های سفارشی دشمن و انتخاب جسد/هدف نکرومنسر حفظ شده‌اند.
- Party: کارت قهرمان، کارت هم‌گروهی‌ها، دشمنان، هدف‌گیری و نوار عملیات از رندرکننده مرکزی استفاده می‌کنند. عملیات و RPCهای موجود گروه دست‌نخورده‌اند.
- PvP: مسیر V1965 حفظ شده و فقط cache-busterها به‌روز شده‌اند.
- دانجن و برج نوع رویارویی هستند و از همان رابط استفاده می‌کنند؛ قوانین محتوایی آن‌ها تغییر نکرده است.

این نسخه یکپارچگی رابط کاربری را تکمیل می‌کند، نه یکسان‌سازی محاسبات و منطق authoritative سرور. موتورهای اجرای Solo/Party/PvP هنوز adapterها و قواعد مختص خود را دارند.
