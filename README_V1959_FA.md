# ETRANOM V1959 — ممیزی تطبیقی موتور مرکزی

این ZIP نسخه کامل پروژه به‌همراه ممیزی V1959 است. برای مشاهده گزارش، فایل `docs/CENTRAL_ENGINE_DIFFERENTIAL_AUDIT_V1959_FA.md` را بخوانید.

V1959 تعداد ۴۸۰ اجرای مهارت (۸۰ مهارت × دو فرم × سه حالت) و ۹۶ اجرای Domain (۸ تخصص × چهار مرحله × سه حالت) را در محیط محلی و ایزوله بررسی می‌کند. این نتایج parity با resolver قدیمی یا سرور Supabase را اثبات نمی‌کنند.

هیچ SQL یا deployی انجام نشده است. مسیر authoritative نبرد تغییر نکرده است.
