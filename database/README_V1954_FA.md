# راهنمای نصب V1954

## فایل اجرایی
فقط این فایل Migration جدید است:

`ETRANOM_V1954_WARRIOR_PVP_COMPLETE.sql`

این Migration تابع مهارت PvP، تابع حمله/دفاع PvP و تابع کمکی چرخه قلمرو جنگجو را به‌روزرسانی می‌کند. تراکنش با BEGIN/COMMIT بسته شده است؛ اگر اجرای فایل با خطا متوقف شود، تغییرات همان تراکنش ثبت نمی‌شوند.

## ترتیب انجام کار
1. از Supabase یک Backup از دیتابیس بگیر.
2. فایل بالا را در SQL Editor اجرا کن.
3. اگر بدون خطا تمام شد، فایل `ETRANOM_V1954_POST_APPLY_VERIFY_READONLY.sql` را اجرا کن.
4. خروجی چهار بخش بررسی را CSV بگیر و برای بررسی نهایی ارسال کن.
5. بعد از موفقیت بررسی، سایت را با فایل‌های همین بسته به‌روزرسانی کن.

## فایل‌هایی که نباید اجرا شوند
- فایل‌های SQL نسخه‌های V1950، V1951 و V1952 را دوباره اجرا نکن.
- فایل‌های داخل `rollback` فقط برای بازگرداندن RPCهای PvP به نسخه مرجع V1948 در صورت بروز مشکل پس از نصب هستند؛ در نصب عادی اجرا نشوند.
- فایل `POST_APPLY_VERIFY_READONLY` فقط‌خواندنی است و تغییری در دیتابیس ایجاد نمی‌کند.

## تغییر داده
این Migration جدول جدید یا ستون جدید نمی‌سازد. تنها تغییر مستقیم داده‌ای، فعال‌کردن مهارت `echo` در کاتالوگ معتبر PvP است؛ چون handler بازتاب ضربه به آن اضافه شده است. مهارت passive با شناسه `incompatible_vessel` همچنان غیرفعال می‌ماند.
