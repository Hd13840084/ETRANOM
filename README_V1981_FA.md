# ETRANOM V1981 — پرتره‌های همراهان نکرومنسر

## محدوده تغییر
- برش و ثبت ۲۰ پرتره مستقل برای مجموعه موجودات رده معمولی نکرومنسر در مسیر `assets/necromancer/companions/`.
- افزودن `manifest.json` برای نگاشت شناسه، نام فارسی/انگلیسی و مسیر تصویر هر موجود.
- اتصال نگاشت پرتره‌ها به کارت همراهان احضارشده در صفحه نبرد.
- اتصال همان پرتره به کارت عضو در پنل پروفایل/مدیریت همراهان.
- در زمان ثبت عضو جدید، اگر گونه با یکی از ۲۰ موجود شناخته‌شده تطبیق داشته باشد، مسیر پرتره اختصاصی ذخیره می‌شود؛ برای موجودات دیگر تصویر قبلی حفظ می‌شود.
- CSS نمایش تصاویر برای کارت نبرد و پروفایل اضافه شد.

## قانون نمایش
برای هر موجود شناخته‌شده، یک فایل واحد در نبرد و پروفایل استفاده می‌شود. اگر عضو قدیمی‌تر باشد و فیلد `portrait` نداشته باشد، رابط با `speciesId` یا نام موجود پرتره را پیدا می‌کند.

## عدم تغییرات
- هیچ تغییری در SQL، ساختار دیتابیس، فرمول مبارزه، آمار هشت‌گانه یا قواعد احضار این نسخه انجام نشده است.
- این انتشار صرفاً دارایی تصویری و اتصال رابط کاربری است.
- فایل‌های پرتره از تصویر مرجع ۲۰تایی به ۲۰ فایل WebP مستقل برش داده شده‌اند.

## بررسی‌ها
- `node --check game.js`
- اعتبارسنجی JSON فایل manifest
- بررسی وجود هر ۲۰ فایل تصویر و استفاده آن‌ها در کد رابط
- تست خودکار V1981 در `tests/v1981/necromancer-companion-portraits.test.mjs`

برای فعال‌شدن روی سایت، محتوای این ZIP باید روی مخزن اصلی جایگزین/ادغام و سپس Hosting منتشر شود. اجرای SQL لازم نیست.
